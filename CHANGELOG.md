# История изменений

## 0.1.0 — первая версия

- Проверка снимков по техническим требованиям Shutterstock: формат, 4–150 Мп, до 50 МБ, цветовой профиль.
- Команды `prepare` и `check` для Claude Code; описания, ключевые слова и категории записываются в `_metadata.jsonl`.
- Проверка метаданных: длина описания, число ключевых слов, категории по списку, запрещённые слова.
- Окно с альбомом, состояниями снимков и карточкой метаданных; разделы, требующие ручной правки, подсвечиваются.
- Редактор: обрезка и выравнивание горизонта, свет и цвет, заплатка, штамп; отмена и возврат оригинала.
- Приём снимков с телефона по Wi-Fi через QR-код; автоматический подхват новых файлов в папке.
- Отправка по FTPS с возобновлением после обрыва; CSV в формате страницы Submit.
- Интерфейс на русском, английском и немецком; тёмная и светлая темы.
- Сборка в exe через PyInstaller.

Проверено на практике: снимки загружены на Shutterstock по FTPS, CSV принят страницей Submit, снимки отправлены на проверку.

Не проверено на практике: приём с настоящего телефона, работа сборки на другом компьютере.
